PROJECT NAME:
TruthLayer AI

PRODUCT OVERVIEW:
TruthLayer AI is an AI-powered fact-checking SaaS platform that verifies factual claims from uploaded PDFs using live web data and LLM reasoning.

The system should:

1. Upload PDF
2. Extract text
3. Detect factual claims
4. Search live web
5. Verify claims
6. Return verdicts:

   * Verified
   * Inaccurate
   * False
